Настоящая Политика определяет порядок обработки и защиты персональных данных при использовании сайта evgenyprudnikov.ru и обращении к Евгению Прудникову.

Редакция от 10.11.2026 Федеральный закон № 152-ФЗ Минимизация персональных данных

1. Общие положения

1.1. Оператор персональных данных — Евгений Прудников (далее — «Оператор»).

1.2. Политика применяется к сайту evgenyprudnikov.ru, его разделам и к персональным данным, которые пользователь добровольно сообщает Оператору при обращении.

1.3. Оператор обрабатывает только те персональные данные, которые необходимы для конкретной цели, не использует их для несовместимых целей и принимает меры по обеспечению конфиденциальности и безопасности.

1.4. Само посещение сайта не означает согласия на обработку специальных категорий персональных данных.

2. Какие данные могут обрабатываться

2.1. Первичное обращение

Форма первичного обращения предназначена для передачи обычных персональных данных в минимальном объёме:

  • имя или псевдоним, указанные пользователем;
  • краткое описание вопроса или жизненной ситуации;
  • контактные сведения или идентификатор аккаунта, которые становятся доступны Оператору после самостоятельной отправки сообщения пользователем через внешний сервис связи;
  • дата и время обращения и иные технические сведения сообщения, предоставляемые выбранным пользователем сервисом связи.

Примеры обычного первичного обращения: «сложности в отношениях с мужем», «не понимаю, как поступить после расставания», «хочу разобраться с тревогой». Такие формулировки сами по себе не являются специальными категориями персональных данных.

2.2. Как работает форма на сайте

Содержимое полей формы не отправляется на сервер сайта и не сохраняется в базе данных сайта. Обработка полей выполняется локально в браузере пользователя только для подготовки сообщения. Оператор получает содержание обращения только после того, как пользователь самостоятельно отправит подготовленное сообщение через внешний сервис связи.

2.3. Технические данные

При обычном открытии сайта сервер хостинга может автоматически обрабатывать технические сведения, необходимые для доставки страницы, защиты и диагностики работы сайта: IP-адрес, дату и время запроса, адрес запрошенной страницы, тип браузера, сведения об операционной системе, код ответа сервера и иные стандартные технические данные.

3. Специальные категории персональных данных

Форма первичного обращения не предназначена для передачи специальных категорий персональных данных. Пользователю предлагается не указывать диагнозы, сведения о состоянии здоровья, интимной жизни, расовой или национальной принадлежности, политических взглядах, религиозных или философских убеждениях.

Если пользователь вопреки предупреждению добровольно направит такие сведения, это не означает, что Оператор запрашивал их через форму. Их дальнейшая обработка допускается только при наличии предусмотренного законом основания. При отсутствии такого основания Оператор не использует такие сведения для заявленной цели и прекращает их обработку в установленном законом порядке.
