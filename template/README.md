# Landing Page Template

This folder contains a reusable English landing page based on the visual system of the main website.

## Files

- `index.html` — page structure and placeholder copy
- `style.css` — responsive layout and visual design
- `script.js` — mobile menu and simple media placeholder switching

## Intended Use

Duplicate this folder and adapt it for a focused audience or offer, for example:

- women
- men
- smoking
- alcohol
- diagnostics

Each landing page should have one clear audience, one primary problem, and one primary call to action.

## Recommended Editing Order

1. Replace the page title and meta description.
2. Rewrite the hero headline and first paragraph for one audience.
3. Replace the six recognition cards with specific client situations.
4. Replace the About section with the specialist's real positioning.
5. Add real testimonials, case stories, and credentials.
6. Replace placeholder media with optimized images.
7. Update the CTA and contact links.
8. Review mobile layout before publishing.

## Design Principle

Keep the page calm, readable, specific, and visually spacious. Avoid excessive claims, too many colors, and multiple competing offers on the same page.
